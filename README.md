# سامانه جامع مدیریت مدارس رشدِ اندیشه (Roshdeandishe)

سامانه جامع و مدرن مدیریت هوشمند مدارس برای دوره‌های تحصیلی ایران (دبستان، متوسطه اول و متوسطه دوم) بازنویسی‌شده با **React، TypeScript، Vite و Tailwind CSS**.

## ویژگی‌ها و قابلیت‌های اصلی

- **معماری چندمستأجره (Multi-Tenant):** پشتیبانی از مدارس متعدد با امکان جابجایی بین مدارس و نقش‌ها در نوار ناوبری.
- **تفکیک کامل نقش‌ها و دسترسی‌ها:**
  - **مدیر کل مدرسه (SCHOOL_ADMIN):** مدیریت پرسنل، تعریف نقش‌های سفارشی، کلاس‌ها، ثبت‌نام و تنظیمات مدرسه.
  - **دبیر و آموزگار (TEACHER):** ثبت نمرات کارنامه، حضور و غیاب کلاسی، طراحی آزمون و بانک سؤالات.
  - **مسئول مالی (FINANCE_ADMIN):** تنظیم شهریه سالانه، تقسیط خودکار، ثبت واریزی‌ها، رسیدها و هزینه‌های جاری.
  - **دانش‌آموز (STUDENT):** مشاهده نمرات، آزمون آنلاین تستی با تایمر لحظه‌ای، حضور و غیاب و برنامه مطالعاتی.
  - **اولیا (PARENT):** پرونده فرزندان، نمرات، غیبت‌ها، برنامه امتحانات و صورتحساب اقساط شهریه.
- **دفتر ثبت نمرات و کارنامه:** نمرات عددی (۰ تا ۲۰) و توصیفی (خیلی خوب، خوب، قابل قبول، نیازمند تلاش) در نوبت‌های مستمر و پایانی.
- **حضور و غیاب کلاسی:** ثبت وضعیت حاضر، دیرآمده، غایب و موجه با امکان ثبت و تایید گواهی پزشکی و چاپ برگه رسمی.
- **آزمون‌های آنلاین تستی:** طراحی تست‌ها، بانک سؤالات طبقه‌بندی‌شده بر اساس فصول کتاب، تایمر زنده و تصحیح خودکار.
- **باکس سؤالات و برگه‌های چاپی:** آرشیو سوالات تشریحی و چاپ استاندارد برگه امتحان با سربرگ مصوب.
- **امور مالی و تقسیط:** محاسبه هوشمند اقساط ماهانه یا فصلی، ثبت فیش، کد رهگیری و اعمال تخفیفات.
- **برنامه‌ریزی مطالعاتی:** پارت‌های هفتگی مطالعه دروس و پیگیری پیشرفت تست‌زنی.
- **برنامه هفتگی کلاس‌ها:** ماتریس زنگ‌های درسی از شنبه تا چهارشنبه.
- **پرتال عمومی مدرسه:** صفحه معرفی و ورود به نشانی `/s/{slug}` برای هر آموزشگاه.

## راه‌اندازی و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه (پورت 3000)
npm run dev

# ساخت نسخه تولیدی
npm run build
```
